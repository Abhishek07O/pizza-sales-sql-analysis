# 🍕 Pizza Sales Analysis Using SQL

## Project Overview
This project analyzes pizza sales data using MySQL to identify business trends, revenue performance, customer ordering patterns, and product performance.

## Tools & Technologies
- MySQL
- SQL
- GitHub
- CSV Dataset

## Dataset
The project uses four CSV files:
- orders.csv
- order_details.csv
- pizzas.csv
- pizza_types.csv

## Business Questions
This project answers 13 business questions, including:
1. Total number of orders.
2. Total revenue generated.
3. Highest-priced pizza.
4. Most common pizza size.
5. Top 5 most ordered pizza types.
6. Quantity of pizzas ordered by category.
7. Distribution of orders by hour.
8. Number of pizza types in each category.
9. Average pizzas ordered per day.
10. Top 3 pizza types by revenue.
11. Category-wise percentage contribution to revenue.
12. Cumulative revenue over time.
13. Top 3 revenue-generating pizzas in each category.

## Project Files
- `PIZZAS.sql` – SQL queries used for analysis.
- CSV files – Raw datasets.
- Portfolio PDF – Project presentation.
